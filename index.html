HinglishGuard: Discord moderation for Hinglish

A Discord bot that removes abuse and religious hate in Hindi and Hinglish, and sends uncertain messages to a human. Fine-tuned HingRoBERTa ensembles plus a local LLM agent that decodes disguised slurs like “ch*tiya”.

Results
Macro-F1 0.744 → 0.800 (offensive) and 0.761 → 0.790 (religious hate); comments handled without a human: 15% → 46%. Tested live on Discord.
Stack
PyTorch, Hugging Face, discord.py, Ollama, Streamlit
Source on GitHub
Agentic RAG, self-hosted LLM

BENNETT ONE: university assistant

Answers students’ questions from 363 official university documents and cites the exact page. A tested rule engine decides eligibility and attendance, never the LLM, and every sentence is checked against its source.

Results
31/31 on a real student-question evaluation (from 72%). Qwen3-14B self-hosted on a campus GPU.
Stack
LangGraph, FastAPI, Qdrant, PostgreSQL, React
Source on GitHub

StockLens: Nifty 50 research

Real prices, reported financials, analyst consensus and news for all 50 Nifty companies, with headline sentiment from FinBERT and a self-hosted LLM that must cite the evidence it uses.
